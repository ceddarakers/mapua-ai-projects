# Mapúa AI Projects

AI-1 to AI-4 coursework projects from the BS Computer Science program at Mapúa University.

## Projects

### Vector-Borne Disease Classification
Classifies vector-borne diseases (dengue, chikungunya, malaria, Zika) from overlapping symptoms. Three models are compared:
- Multinomial Logistic Regression
- Decision Trees
- Support Vector Machine (SVM)

**Tools:** Python, scikit-learn, Jupyter Notebook

### Optimizing Urban Pedestrian Networks
An IEEE-format paper on using AI to design walkable and accessible cities by optimizing pedestrian networks.

**Format:** IEEE paper (PDF)

### Philippine Labor Code Assistant
Evaluates open-source large language models for Philippine legal assistance using Retrieval-Augmented Generation (RAG) over the Philippine Labor Code. Includes the notebook and the presentation deck.

**Tools:** Python, open-source LLMs, RAG, Jupyter Notebook

### Pose Estimation + Exercise Classifier
Real-time exercise classification on a Raspberry Pi 5. MediaPipe BlazePose extracts pose keypoints from a webcam feed, and a dual-head LSTM identifies 9 functional movement exercises and scores form quality. A post-session RAG chat gives coaching feedback. See the project's own README for setup and details.

**Tools:** Python, MediaPipe, TensorFlow Lite, LSTM, ONNX, Groq, Raspberry Pi 5

## Notes
These are group projects completed with classmates at Mapúa University's School of Information Technology.
